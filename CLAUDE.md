# Scam Lens - Project Instructions

## Project

Scam Lens is an AI-powered scam detection and awareness application.

## Tech Stack

- HTML
- CSS
- JavaScript
- AI

## Coding Conventions

- Keep code clean and readable.
- Use meaningful variable and function names.
- Keep functions focused and reusable.
- Do not hardcode API keys or secrets.
- Keep the interface simple and accessible.

## UI Guidelines

- Use a clean and trustworthy interface.
- Make scam warnings easy to understand.
- Clearly communicate risk levels.
- Provide understandable explanations.

## Git

Use Conventional Commits.

Examples:

- feat: add message analysis
- fix: improve scam detection
- docs: update README
- chore: update configuration
## Development Principle

Prioritize clarity, usability, and responsible communication when presenting scam-risk results to users.
